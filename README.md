## 适合谁、不适合谁

适合的场景：个人博客和轻量 WordPress 站、开发测试环境、代理和流媒体、机器人与定时任务、数据采集，以及需要加拿大 IP 或北美地理多样性的部署。硬件层面，套餐用的是 Intel Xeon E5 系列 CPU（主频 2.6–3.0GHz，Geekbench 单核 700–800 分），SSD RAID-10 阵列读写 500–900MB/s，跑上面这些任务绰绰有余。

不适合的场景也要直说：

- **CPU 密集型应用**：E5 系列是老架构，跑编译农场、高频计算会很吃力。
- **大流量中文网站**：晚高峰速度有波动，第三方评测明确建议这类需求选 CN2 GIA 类线路。
- **需要 Windows 的用户**：普通 VPS 套餐不支持 Windows，系统可选 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu，自定义 ISO 需提交工单申请。
- **想要托管服务的团队**：RackNerd 的 VPS 是非托管（unmanaged）产品，运维自己负责，客服是 24/7 工单制，响应通常在 30 分钟以内。

还有一个容易忽略的选套餐依据：如果你打算用一键应用跑 AI 工具，内存门槛要提前对号。ctrl 面板里 n8n 和 Coolify 2 GB 就能跑，AnythingLLM、Ollama、LibreChat 需要 4 GB 起，OpenClaw 要 8 GB 起。只跑博客和轻量应用的，1 GB 档足够，多花的钱没有意义。
